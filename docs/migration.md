# Migrating from uiuc.chat

The community instance at [uiuc.chat](https://uiuc.chat/) is migrating to the official campus-supported instance at [chat.illinois.edu](https://chat.illinois.edu/).

As part of this process, **chatbot creation on uiuc.chat has been disabled** — please create new chatbots on chat.illinois.edu.

## Migrating an existing chatbot

If you have a chatbot on uiuc.chat and would like help moving its files to the new instance:

1. **Create a new chatbot** on [chat.illinois.edu](https://chat.illinois.edu/) — it does not have to have the same name as the old one.
2. **Fill out the migration form**: [forms.illinois.edu/sec/944673135](https://forms.illinois.edu/sec/944673135).
3. **Customize the new chatbot** and add users to it.
4. The team will contact you within about two weeks to schedule the file migration — they can move all your files, or you can start from scratch.

!!! warning "Chat history is not migrated"
    Only files can be migrated. Conversation history stays on the old instance, and chatbots themselves must be re-created manually on chat.illinois.edu.
